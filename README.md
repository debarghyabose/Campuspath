## 🌐 Project Overview

CampusPath 3D is an academic project developed as part of the **Data Structures and Algorithms (DSA) coursework under the Department of Electronics and Communication Engineering (ECE), Institute of Engineering & Management (IEM), Kolkata.**

The project aims to demonstrate how fundamental computer science concepts, particularly graph theory, data structures, and shortest-path algorithms, can be applied to solve a practical real-world problem: university campus navigation.

The application creates an interactive three-dimensional representation of the IEM campus and models its buildings and pedestrian pathways as a weighted graph.

Users can select their starting point and destination, calculate an efficient walking route, and visualize the navigation path within the 3D campus environment.

Beyond implementing theoretical DSA concepts, this project demonstrates their practical integration with modern frontend development and interactive 3D technologies.

### 🎯 Academic Learning Objectives

- Understand graph representation using adjacency lists.
- Implement and apply shortest-path algorithms.
- Understand priority queues and minimum heaps.
- Explore graph traversal and weighted graph concepts.
- Apply DSA concepts to a practical navigation problem.
- Integrate algorithmic logic with a real-time interactive 3D interface.
